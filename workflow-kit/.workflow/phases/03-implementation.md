# Phase 4 : Implémentation

## Objectif
Implémenter les tasks une par une, en suivant le plan, avec vérification à chaque étape.

## Checklist par task

### Avant de coder
- [ ] `current-epic.md` lu, task identifiée
- [ ] `conventions.md` et overlay techno lus
- [ ] Task marquée `in_progress` dans `current-epic.md`
- [ ] Le plan de l'Architecte est clair pour cette task

### Pendant le code
- [ ] Un seul fichier modifié (2-3 max si couplés)
- [ ] Imports vérifiés (fichiers existants)
- [ ] Noms cohérents avec les conventions
- [ ] APIs/méthodes utilisées → existence vérifiée
- [ ] Pas de code placeholder silencieux
- [ ] TODO: explicites pour tout code incomplet

### Après le code
- [ ] Le code compile / tourne sans erreur
- [ ] Task marquée `done` dans `current-epic.md`
- [ ] Aucun écart par rapport au plan (sinon → signaler)

## Règle de blocage
Si un problème non prévu surgit :
1. STOP — ne pas contourner
2. Signaler à l'Orchestrateur
3. Si c'est un problème d'archi → escalader à l'Architecte
4. Si c'est un manque d'info → déployer le Researcher
5. Ne reprendre qu'après résolution
