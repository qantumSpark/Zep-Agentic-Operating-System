# Product Brief

## Vision

ZAOS est un cockpit desktop de vibe coding avec guard rails forts. L'utilisateur pilote le developpement d'applications et de jeux par intention, arbitrage, validation et preuves — sans avoir besoin de lire le code la plupart du temps. Le systeme est concu Claude-first mais agnostic-ready, avec une trajectoire vers le support multi-runtime (Codex, LLMs futurs).

## Pour qui

Developpeur solo qui utilise des agents IA pour construire des produits vendables. Le standard de qualite vise est celui d'un produit commercialisable : robuste, maintenable, et suffisamment poli pour etre presente a des utilisateurs finaux.

## Pourquoi

Claude Code en terminal brut ne suffit pas pour piloter un projet complet de maniere fiable. Il manque la structure (workflow, gates, guard rails), la memoire produit (brief, acceptance checks, session insights), la visibilite (dashboard temps reel, preuves visuelles) et le controle (policy engine, permissions contextuelles). ZAOS comble ce fossé entre un agent IA puissant et un processus de developpement rigoureux.

## Contraintes

- Incremental : pas de big-bang rewrite, partir de l'existant
- Windows desktop uniquement (Tauri v2)
- Claude comme runtime actif, mais decoupler progressivement
- Ameliorer la memoire et les session insights en priorite
- Trajectoire vers LLM agnostic et integration Codex
- Qualite vendable : chaque feature doit etre robuste, pas juste fonctionnelle

## Hors-scope

- Multi-utilisateur / collaboration
- Deploiement cloud / SaaS
- Support Linux / macOS
- Marketplace de workflows ou de plugins
- Support complet d'un second runtime dans l'immediat

## Definition de succes

ZAOS a reussi quand il est suffisamment robuste pour etre utilise comme outil principal de developpement d'applications et de jeux vendables, et que les projets construits avec sont maintenables dans la duree. Concretement : un workflow fiable de bout en bout, une memoire produit qui survit entre les sessions, des guard rails qui empechent les erreurs couteuses, et une qualite globale qui justifierait un prix.
