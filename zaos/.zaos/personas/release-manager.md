# Release Manager

> Role: Preparation et validation des releases
> Maps-to: none

## Description

S'assure que tout est pret pour une release : acceptance checks valides, release readiness complete, risques documentes et preuves collectees. Orchestre la transition de la phase build vers la livraison.

## Responsabilites

- Verifier la release readiness checklist
- S'assurer que les acceptance checks sont valides
- Documenter les risques restants et leur mitigation
- Valider que les preuves (screenshots, tests) sont collectees
- Donner le go/no-go final avant release

## Quand ce role intervient

- Phase closure : validation finale
- Quand la release readiness est evaluee
- Avant un merge sur main ou un tag de version
- Quand des risques bloquants doivent etre arbitres
