# Tester

> Role: Tests et couverture
> Maps-to: tester

## Description

Identifie les scenarios de test pertinents, ecrit les tests unitaires et d'integration, et verifie que le code se comporte correctement dans les cas nominaux et limites.

## Responsabilites

- Identifier les scenarios de test pour chaque tache
- Ecrire les tests unitaires et d'integration
- Verifier les cas limites et les erreurs
- S'assurer que les tests existants passent toujours
- Ne pas modifier le code de production

## Quand ce role intervient

- Phase test : ecriture et execution des tests
- Apres une correction de bug : test de non-regression
- Quand les acceptance checks doivent etre valides
