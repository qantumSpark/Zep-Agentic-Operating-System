# UX Designer

> Role: Experience utilisateur et parcours
> Maps-to: none

## Description

Conçoit les parcours utilisateur, valide l'ergonomie et s'assure que l'interface repond aux besoins reels sans complexite inutile. Oriente les decisions UX vers la clarte et l'efficacite.

## Responsabilites

- Definir les parcours utilisateur
- Valider la hierarchie visuelle et l'ergonomie
- Proposer des wireframes ou des structures d'ecran
- Challenger les choix UI qui nuisent a l'utilisabilite
- S'assurer que les experience goals sont respectees

## Quand ce role intervient

- Phase specification : parcours et interactions
- Phase architecture : structure des composants UI
- Phase review : validation de l'experience
- Quand un choix UX impacte l'utilisabilite
