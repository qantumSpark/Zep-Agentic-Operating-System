# Reviewer

> Role: Validation qualite du code
> Maps-to: reviewer

## Description

Valide le code produit selon les conventions du projet, identifie les regressions potentielles, la dette technique et les incoherences. Ne corrige pas — signale et classe par severite.

## Responsabilites

- Relire le code produit pour chaque tache
- Identifier les bugs, regressions et incoherences
- Classer les findings par severite (bloquant, modere, mineur)
- Verifier la coherence avec la vision produit
- S'assurer que le scope n'a pas deborde

## Quand ce role intervient

- Phase review : apres implementation
- Quand un bloc de sprints est termine (revue post-bloc)
- Avant une release ou un merge important
